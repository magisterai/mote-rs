[total order](022-4-1-6-simple-type-definition-for-anysimpletype.md#dt-total-order)
:   A **total order** is an [·partial order·](022-4-1-6-simple-type-definition-for-anysimpletype.md#dt-partial-order)
    such that for no *a* and *b*
    is it the case that *a <> b*.

[union](004-2-3-lexical-space.md#dt-union)
:   **Union**
    datatypes are those whose [·value space·](003-1-4-terminology.md#dt-value-space)s and
    [·lexical space·](004-2-3-lexical-space.md#dt-lexical-space)s are the union of
    the [·value space·](003-1-4-terminology.md#dt-value-space)s and
    [·lexical space·](004-2-3-lexical-space.md#dt-lexical-space)s of one or more other datatypes.

[user-derived](006-2-5-2-3-derived-by-union.md#dt-user-derived)
:   **User-derived** datatypes are those [·derived·](005-2-5-1-3-union-datatypes.md#dt-derived)
    datatypes that are defined by individual schema designers.

[Validation Rule](003-1-4-terminology.md#dt-cvc)
:   **Validation Rule**

[value space](003-1-4-terminology.md#dt-value-space)
:   A **value
    space** is the set of values for a given datatype.
    Each value in the **value space** of a datatype is denoted by
    one or more literals in its [·lexical space·](004-2-3-lexical-space.md#dt-lexical-space).
