#### 3.3.16 long

<a id="dt-long"></a>

[Definition:]
**long** is
[·derived·](005-2-5-1-3-union-datatypes.md#dt-derived) from [integer](015-3-3-10-1-constraining-facets.md#integer) by setting the
value of [·maxInclusive·](028-4-3-6-1-the-whitespace-schema-component.md#dt-maxInclusive) to be 9223372036854775807
and [·minInclusive·](031-4-3-10-mininclusive.md#dt-minInclusive) to be -9223372036854775808.
The [·base type·](005-2-5-1-3-union-datatypes.md#dt-basetype) of **long** is
[integer](015-3-3-10-1-constraining-facets.md#integer).

<a id="long-lexical-representation"></a>

##### 3.3.16.1 Lexical representation

**long** has a lexical representation consisting
of an optional sign followed by a finite-length
sequence of decimal digits (#x30-#x39). If the sign is omitted, "+" is assumed.
For example: -1, 0,
12678967543233, +100000.

<a id="long-canonical-repr"></a>

##### 3.3.16.2 Canonical representation

The canonical representation for **long** is defined
by prohibiting certain options from the
[Lexical representation (§3.3.16.1)](016-3-3-16-long.md#long-lexical-representation). Specifically, the
the optional "+" sign is prohibited and leading zeroes are prohibited.

#### 3.3.20 nonNegativeInteger

<a id="dt-nonNegativeInteger"></a>

[Definition:]
**nonNegativeInteger** is [·derived·](005-2-5-1-3-union-datatypes.md#dt-derived) from
[integer](015-3-3-10-1-constraining-facets.md#integer) by setting the value of
[·minInclusive·](031-4-3-10-mininclusive.md#dt-minInclusive) to be 0. This results in the
standard mathematical concept of the non-negative integers. The
[·value space·](003-1-4-terminology.md#dt-value-space) of **nonNegativeInteger**
is the infinite set {0,1,2,...}. The [·base type·](005-2-5-1-3-union-datatypes.md#dt-basetype) of
**nonNegativeInteger** is [integer](015-3-3-10-1-constraining-facets.md#integer).

<a id="nonNegativeInteger-lexical-representation"></a>

##### 3.3.20.1 Lexical representation

**nonNegativeInteger** has a lexical representation consisting of
an optional sign followed by a finite-length
sequence of decimal digits (#x30-#x39). If the sign is omitted,
the positive sign ("+") is assumed.
If the sign is present, it must be "+" except for lexical forms
denoting zero, which may be preceded by a positive ("+") or a negative ("-") sign.
For example:
1, 0, 12678967543233, +100000.

<a id="nonNegativeInteger-canonical-repr"></a>

##### 3.3.20.2 Canonical representation

The canonical representation for **nonNegativeInteger** is defined
by prohibiting certain options from the
[Lexical representation (§3.3.20.1)](016-3-3-16-long.md#nonNegativeInteger-lexical-representation). Specifically, the
the optional "+" sign is prohibited and leading zeroes are prohibited.
