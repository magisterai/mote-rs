Description: Computes a value using the function designated by function-number, using the arguments in

Arguments:

               Name            Type                                Description

          number                            below.
          argument-list   number            Each argument in argument-list is passed to the called

               function-number            function-number             Function
           (includes hidden values)   (excludes hidden values)
          1                           101                         AVERAGE

          6                           106                         PRODUCT
          7                           107                         STDEV
          8                           108                         STDEVP
          9                           109                         SUM
          10                          110                         VAR
