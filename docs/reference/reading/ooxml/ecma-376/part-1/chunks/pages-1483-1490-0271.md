```text
                                                                          17. WordprocessingML Reference Material


This pattern consists of a mask that is applied over the background shading color to get the locations where the
pattern color should be shown. Each of these possible masks is shown in the enumeration values below. In each
example, an 8 pixel by 8 pixel mask is displayed where black has been used as the fill color (the parent element’s
fill attribute), and white has been used as the pattern color (the parent element’s color attribute). When the
shading is applied, the mask is tiled as necessary to match the size of the shaded area.

[Example: Consider a shaded paragraph which uses a 10 percent foreground fill, resulting in the following
WordprocessingML:

   <w:shd w:val="pct10" …/>

This shading val is pct10, indicating that the border style is a 10 percent foreground fill mask. end example]
```
