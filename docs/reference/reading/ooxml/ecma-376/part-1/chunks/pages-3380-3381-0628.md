21.2.2        Elements
In DrawingML, charts define a visualization of numeric data. The definition includes where the data shall come
from, a cache of the data, and how the data shall be represented graphically. Other DrawingML elements are
reused to define aspects of the formatting of the visualization.

See the informative material in Annex L for a description and overview of the basic chart types and chart
components.

21.2.2.1          applyToEnd (Apply to End)
This element specifies the picture shall be applied to the end of the point or series.
