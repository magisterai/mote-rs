sz (Border Width)   Specifies the width of the current border.

                    If the border style (val attribute) specifies a line border, the width of this border is
                    specified in measurements of eighths of a point, with a minimum value of two (one-
                    fourth of a point) and a maximum value of 96 (twelve points). Any values outside this
                    range can be reassigned to a more appropriate value.

                    If the border style (val attribute) specifies an art border, the width of this border is
                    specified in measurements of points, with a minimum value of one and a maximum value
                    of 31. Any values outside this range can be reassigned to a more appropriate value.
