          EXACT ( string-1 , string-2 )
Description: Performs a case-sensitive, character-by-character, lexical comparison of string-1 and string-2.

Arguments:

              Name                Type                               Description
          string-1         text              The two strings to be compared.
          string-2         text


Return Type and Value: logical – TRUE if string-1 and string-2 have the exact same length and contents;
otherwise, FALSE.

[Example:

EXACT("ABC","ABCD") results in FALSE
EXACT("Abc","aBC") results in FALSE
EXACT("","") results in TRUE

end example]

         x = argument x
         λ = argument lambda

Arguments:

              Name              Type                                Description
          x               number             The value at which the function is evaluated.
          lambda          number             The inverse of the mean.
          cumulative-     logical            Determines the form of the function. If TRUE,
          flag                               EXPONDIST returns the cumulative distribution function;
                                             if FALSE, EXPONDIST returns the probability density
                                             function.
