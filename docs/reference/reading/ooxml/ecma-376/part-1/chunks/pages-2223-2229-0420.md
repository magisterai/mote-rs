18.17.7.128         FTEST
Syntax:

          FTEST ( array-1 , array-2 )
Description: Computes the result of an F-test.

Arguments:

              Name               Type                                  Description
          array-1         number, name,        If an array or reference argument contains text, logical
          array-2         array, reference     values, or empty cells, those values are ignored;
                          to number            however, cells with the value 0 are included.

         The number of data points in array-1 or array-2 is less than 2, the return value is unspecified.
