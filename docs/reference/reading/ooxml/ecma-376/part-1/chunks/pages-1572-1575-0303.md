18.2.12        fileSharing (File Sharing)
This element tracks file sharing settings for the workbook. When a password is to be hashed and stored in this
element, it shall be hashed starting from a UTF-16LE encoded string value. If there is a leading BOM character
(U+FEFF) in the encoded password it is removed before hash calculation.
