```text
18.18.56 ST_PhoneticAlignment (Phonetic Alignment Types)
Phonetic alignment settings. These specify how to align the phonetic text, which represent the sounds, above
the base text or base word.

This simple type's contents are a restriction of the W3C XML Schema string datatype.

This simple type is restricted to the values listed in the following table:
                  Enumeration Value                                                Description
center (Center Alignment)                                    Center the phonetic characters over the base word,
                                                             per word.
distributed (Distributed)                                    Each phonetic character is distributed above each base
                                                             word character, per word.

```

```text
This simple type's contents are a restriction of the W3C XML Schema string datatype.

                  Enumeration Value                                                Description
```
