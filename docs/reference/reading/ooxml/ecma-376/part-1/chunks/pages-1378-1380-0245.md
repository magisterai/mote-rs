17.18.16 ST_DocPartGallery (Entry Gallery Types)
This simple type specifies possible settings for the predefined gallery into which a glossary document part shall
be classified. This classification, although its enumeration values can be interpreted to imply semantics around
the contents of the parent glossary document entry, shall only be used to classify and sort this entry (via an
application or a user interface).
