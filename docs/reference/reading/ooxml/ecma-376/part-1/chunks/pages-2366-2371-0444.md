          ROUND ( x , number-digits )
Description: Rounds x to the number of digits specified by number-digits.

Arguments:

              Name            Type                                  Description
          x               number            The value to be rounded.
          number-digits   number            The number of digits to which x is to be rounded. If
                                            number-digits is greater than 0, x is rounded to the
                                            specified number of decimal places. If number-digits is 0,
                                            x is rounded to the nearest integer. If number-digits is
                                            less than 0, x is rounded to the left of the decimal point.


Return Type and Value: number – The rounded value of x. When rounding, digits 0–4 round down, while
digits 5–9 round up.

[Example:
