17.6.9        paperSrc (Paper Source Information)
This element specifies printer-specific settings for the printer tray(s) that shall be used to print different pages in
this section in the document.

[Example: Consider a section which must use the best possible tray when printing all pages in this section. This
information is specified using the following WordprocessingML:

   <w:paperSrc w:first="1" w:other="1" />

The attributes on the paperSrc element specify the printer codes for the trays to be used when printing this
section. end example]
