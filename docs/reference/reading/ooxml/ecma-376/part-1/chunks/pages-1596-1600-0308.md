18.2.30       workbookView (Workbook View)
This element specifies a single Workbook view.

Units for window widths and other dimensions are expressed in twips. Twip measurements are portable
between different display resolutions. The formula is (screen pixels) * (20 * 72) / (logical device dpi), where
the logical device dpi can be different for x and y coordinates.

18.3        Worksheets
Sheets are the central structures within a workbook, and are where the user does most of their spreadsheet
work. The most common type of sheet is the worksheet, which is represented as a grid of cells. Worksheet cells
can contain text, numbers, dates, and formulas. Cells can be formatted as well. Workbooks usually contain more
than one sheet. To aid in the analysis of data and making informed decisions, spreadsheet applications often
implement features and objects which help calculate, sort, filter, organize, and graphically display information.
