simple type mirrors exactly the simple type ST_LinearDirection with the addition of none.

different starting elements are:

different rotation types are:

within the diagram. The different places to put the first node are:

The simple type ST_AnimLvlStr acts very much like the simple type ST_AminOneStr, as it allows for two

diagram. The following allows for differentiation of radial diagrams. The different options are:

       none – nothing

       ctr – allows a radial diagram to be shown with the center node first
