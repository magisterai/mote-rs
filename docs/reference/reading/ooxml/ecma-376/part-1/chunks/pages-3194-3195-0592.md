21. DrawingML - Components Reference
    Material

The subordinate subclauses specify the semantics for the XML markup comprising DrawingML content, which
can be used within the contents of WordprocessingML, SpreadsheetML, or PresentationML documents.

This portion of DrawingML describes components built on top of the previously defined framework to create
charts, diagrams, etc..

21.1          DrawingML - Main
The following parts of the DrawingML Main namespace define additional base constructs for all kinds of
DrawingML objects (e.g., paragraphs, text, tables, etc.).
