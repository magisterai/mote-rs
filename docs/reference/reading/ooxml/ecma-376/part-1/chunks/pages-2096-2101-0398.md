Description: Tests if all arguments in argument-list are TRUE. The function evaluates all arguments prior to
returning a value.

Arguments:

             Name                Type                                 Description
          argument-list   logical, array, or   The arguments in argument-list designate the values to be
                          cell reference       tested. For an array or cell reference, a cell that contains
                                               text or is empty shall be ignored.


Return Type and Value: logical – TRUE if all arguments in argument-list are TRUE; otherwise, FALSE.

However, if no logical values are found, #VALUE! is returned.

[Example:

AND(TRUE) results in TRUE
AND(TRUE,FALSE) results in FALSE
