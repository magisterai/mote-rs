17.18.79 ST_ShortHexNumber (Four Digit Hexadecimal Value)
This simple type specifies a number value specified as a two octet (four digit) hexadecimal number, whose
contents are interpreted based on the context of the parent XML element.

[Example: Consider the following value for a node of type ST_ShortHexNumber: 2F6C.
