21.1.3.14       tblGrid (Table Grid)
This element defines a list of table column (§21.1.3.2) elements. There should be a table column (§21.1.3.2)
element for every column held within the table.

[Example: Consider the following example of a tblGrid within DrawingML:

   <a:tblGrid>
     <a:gridCol w="1117600"/>
     <a:gridCol w="1117600"/>
     <a:gridCol w="1117600"/>
   </a:tblGrid>

In this example, we have a tblGrid defined that holds three columns, therefore the table has three columns.
end example]

[Note: The W3C XML Schema definition of this element’s content model (CT_TableGrid) is located in §A.4.1. end
note]

21.1.3.15       tblPr (Table Properties)
This element defines the properties of a table on the whole. Within this element are many visual modifications
that can be applied to the table.

[Example: Consider the following example of a tblPr within DrawingML:

   <a:tblPr firstRow="1" bandRow="1">
     <a:tableStyleId>{5940675A-B579-460E-94D1-54222C63F5DA}</a:tableStyleId>
