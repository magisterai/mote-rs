17.13.5.30        rPrChange (Revision Information for Run Properties on the Paragraph Mark)
This element specifies the details about a single revision to a set of run properties applied to a paragraph mark
within a WordprocessingML document.

This element stores this revision as follows:

       The child element of this element contains the complete set of run properties which were applied to this
        paragraph mark before this revision
       The attributes of this element contain information about when this revision took place (i.e. when these
        properties became a 'former' set of run properties).
