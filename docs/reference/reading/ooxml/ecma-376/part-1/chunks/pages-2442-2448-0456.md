18.17.7.356        ZTEST
Syntax:

          ZTEST ( array , test-value [ , sigma ] )
Description: Computes the one-tailed probability-value of a z-test. For a given hypothesized population mean,
test-value, ZTEST returns the probability that the sample mean would be greater than the average of
observations in the data set array; that is, the observed sample mean.
