```text
L.4.13.1.4          Chart Styles
Charts can have different styles applied to them. This is essentially just a coordinated set of coloring and
formatting that is applied across an entire chart and all its elements. Styles allow a quick and easy way
to coordinate the look and feel of a chart with the rest of the document. Below is a rendering of a
column chart and pie chart showing the same data, with the same style applied. There is also a shot of
many different types of styles. It is shown for both charts to illustrate how the idea of a style can apply,
and be consistent, across different chart types.




4914
```
