L.6.1.1         Accent Object
The accent object is used to represent any baseline text having a combining diacritical mark placed
above the base. The accent has only one child, the base element. The accent mark itself is stored as a
property.

For example, consider the following letters having diacritical marks:



                                                  𝑎̇ 𝑎̈ 𝑎̃ 𝑎̂ 𝑎⃗
