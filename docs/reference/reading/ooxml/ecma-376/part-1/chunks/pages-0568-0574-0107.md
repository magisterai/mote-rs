17.6.4         cols (Column Definitions)
This element specifies the set of columns defined for this section in the document.

[Example: Consider a document in which a section defines two columns of 4.16" and 1.83", respectively,
resulting in the following WordprocessingML:

   <w:cols w:equalWidth="0">
     <w:col w:w="2640" w:space="720"/>
     <w:col w:w="6000"/>
   </w:cols>

The cols element defines the set of columns defined for this section, which because equalWidth is 0, are
defined by the number of col elements contained in the column definition. In this case, the first column is 2,640
twentieths of a point wide (as 2640/1440ths of an inch equals 1.83 inches) with one-half of an inch space after,
and the second column is 6,000 twentieths of a point wide (4.16 inches). end example]

Based on the presence of the equalWidth attribute, a consumer shall render the columns using:

         If equalWidth is true, then the columns are defined using the data stored as attributes of the cols
          element (defined below).
         If equalWidth is false, then the columns are defined using the presence and data on each child col
          element (§17.6.3).

page for all East Asian text content in this section.
