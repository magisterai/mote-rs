19.1.2.4          f (Single Formula)
This element defines a single value as the result of the evaluation of an expression. The expression is defined by
the eqn attribute and has the general form of an operation followed by up to three arguments, which consist of
adjustment values (see the adj attribute of the shape element (§19.1.2.19)), the results of earlier formulas, fixed
numbers or pre-defined values. Each f value is referenced using "@" followed by a number corresponding to the
zero-based index for that value in the list of f elements. [Example: For example, the value of the second f
element is referenced as "@2". end example]

[Example: The following defines a blue arrow pointing to the right:

   <v:shape coordsize="21600,21600" adj="18000,5400,10800"
     path="m @0,0 l @0,@1 0,@1 0,@3 @0,@3 @0,21600 21600,10800 x e"
     style='left:50pt;top:50pt;width:90pt;height:30pt'
     fillcolor="#4f81bd" strokecolor="#4f81bd" strokeweight="2pt">
     <v:formulas>
      <v:f eqn="val #0"/>
      <v:f eqn="val #1"/>
      <v:f eqn="val #2"/>
