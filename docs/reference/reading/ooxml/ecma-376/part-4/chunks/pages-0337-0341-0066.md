19.1.2.2          background (Document Background)
This element describes the fill of the background of a page using vector graphics fills. Fills consist of simple
colors, more advanced effects defined through the fill element (§19.1.2.5), or images.

[Example: The following shades the page background a pale red:

   <v:background fillcolor="#c0504d">
   </v:background>

This uses the fill element (§19.1.2.5) to create a gradient background fill:

   <v:background>
    <v:fill type="gradient" color="#c0504d" color2="#f0504d" angle="45"/>
   </v:background>

end example]
