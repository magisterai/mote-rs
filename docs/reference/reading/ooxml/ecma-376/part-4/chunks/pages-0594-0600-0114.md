19.1.2.19         shape (Shape Definition)
This element is used to describe a shape, the core object in VML. This element can appear by itself or within a
group element (§19.1.2.7). If a shapetype element (§19.1.2.20) is referenced using the type attribute, any
attributes specified in the shape override those found in the shapetype.

[Example:

   <v:shape style="position:absolute;top:50;left:20;width:50;height:50"
     path="m 0,0 l 0,1000 1000,1000 1000,0 x e">
     <v:shadow on="true" type="perspective"
       matrix="1.25,-2,,1.5,,.000001" offset="38pt,-6pt"/>
   </v:shape>

   <v:shape style="position:absolute;top:50;left:20;width:50;height:50"
     fillcolor="yellow" path="m 0,0 l 0,1000 1000,1000 1000,0 x e">
