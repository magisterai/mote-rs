```text
19.1.2.23         textpath (Text Layout Path)
This element is used to define a vector path based on the text data, font and font styles supplied. The path
which results is then mapped into the region defined by the v attribute of the shape's path (§19.1.2.14).

[Example:

   <v:curve from="50,100" to="400,100"
     control1="200,200" control2="300,200">
     <v:stroke color="blue"/>
     <v:fill color="yellow" color2="green" type="gradient"/>
     <v:path textpathok="true"/>
     <v:textpath on="true" style="font:normal normal normal 36pt Arial"
       fitpath="true" string="Hello, VML!"/>
   </v:curve>

```
