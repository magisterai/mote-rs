19.1.2.7         group (Shape Group)
This element is used to collect shapes and groups so they can be positioned and transformed as a single unit. A
group contains group, shapetype, shape, pre-defined shape - arc, curve, image, line, oval, polyline, rect,
roundrect - and lock elements.
