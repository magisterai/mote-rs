19.1.2.5          fill (Shape Fill Properties)
This element specifies how the path should be filled if something beyond a solid color fill is desired. The
attributes of the fill element can be used to describe a powerful set of image- or gradient-based fill
patterns. Extensions to the VML fill definition are encoded as sub-elements of fill.
