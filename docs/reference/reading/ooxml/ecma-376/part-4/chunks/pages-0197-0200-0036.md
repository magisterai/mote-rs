14.10.6       fldData (Custom Field Data)
This element specifies custom field data which shall be associated with the parent field. No information or
semantics are applied to the contents of this data by ECMA-376, and therefore this field can be used as desired
to store additional application-defined data with the field. However, applications should not lose the contents of
this custom data if they do not understand or utilize it (i.e. the information should continue to be saved with the
file).

If this element is omitted, then no custom field data is stored with the parent field.

[Example: Consider the following WordprocessingML fragment for a simple field:

   <w:fldSimple w:instr="PRIVATE">
     <w:fldData xml:space="preserve">///3645ERKJHE</w:fldData>
   </w:fldSimple>

The fldData element contains custom data stored with this PRIVATE field (Part 1, §17.16.5.48), the contents of
which are determined by a hosting application. end example]
