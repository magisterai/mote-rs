19.1.2.20        shapetype (Shape Template)
This element defines a shape template that can be used to create other shapes. Shapetype is identical to the
shape element (§19.1.2.19) except it cannot reference another shapetype element. The type attribute shall not
be used with shapetype. Attributes defined in the shape override any that appear in the shapetype. CSS
positioning attributes (such as top, width, z-index, rotation, flip) are not passed to a shape from a
shapetype. To use this element, create a shapetype with a specific id attribute. Then create a shape and
reference the shapetype's id using the type attribute.

[Example:

   <v:shapetype id="mytype" fillcolor="silver" strokecolor="blue">
     <v:path v="m 0,0 l 0,1000, 1000,1000, 1000,0 x e"/>
     <v:fill on="true" type="gradient" color2="navy" angle="-45"/>
