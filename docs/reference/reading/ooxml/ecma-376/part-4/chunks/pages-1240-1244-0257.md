                                     Schemas – RELAX NG

     This annex is informative.

     B.1         General
     This Office Open XML specification includes a family of schemas defined using the RELAX NG syntax. The
     definitions of these schemas follow below, and they also reside in an accompanying file named OfficeOpenXML-
     RELAXNG-Transitional.zip, which is distributed in electronic form.

     As well as the differences between RELAX NG and XML Schemas described in Part 1, §B, “Schemas – RELAX NG”,
     here are some other differences:

                 The RELAX NG schemas represent co-occurrence constraints between elements and attributes. For
                  example, pml.rnc specifies that the pic element and the attribute spid in p_CT_OleObject are
                  mutually exclusive. Meanwhile, pml.xsd simply allows both in CT_OleObject.
                 VML drawing parts (§8.1) can be validated against RELAX NG schemas, but cannot be validated
                  against XSD schemas. This is because there are no XSD schemas for the unqualified xml element,
                  which is the root element of VML drawing parts.
