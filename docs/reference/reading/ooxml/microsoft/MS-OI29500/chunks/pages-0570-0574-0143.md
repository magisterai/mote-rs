     elements.

     element.

a.   The standard states that the maxOccurs value for the extLst child element is unbounded.

     In Office, child element fmtId has a maximum value of 2147483647.

     Office limits the occurrences of this choice to 4.

a.   The standard states that the pageMargins child element is optional.

     In Office, if no child pageMargins element is defined, a pageMargins element is created with
     application defined values.

     In Office, this element to controls how a user is permitted to interact with the chart regardless of
     whether the chart is on a protected worksheet or chart sheet.
