3.5.4 Custom XSN

The Custom XSN is comprised of a Custom XML Data Storage Part ("[ISO/IEC-29500-1] §15.2.5")
which contains the Custom XSN information, and a Custom XML Data Storage Properties Part
("[ISO/IEC-29500-1] §15.2.6") which contains the set of properties for the custom XML data.

 The XML contents of the data storage part conform to the schema defined in Custom XSN Schema
(§3.5.4.1, Custom XSN Schema).

The root element of the Custom XML Data Storage Part shall be customXsn (§3.5.4.1.1.2,
customXsn).

The Associated XML Schema ("[ISO/IEC-29500-1] §22.5.2.2; schemaRef") for this Custom XML Data
Storage Part shall be “http://schemas.microsoft.com/office/2006/metadata/customXsn”.


3.5.4.1 Custom XSN Schema

A CustomXSN defines the source location and Document Information Panel behaviors for the
document. CustomXSN is used in conjunction with Content Type Schema (§3.5.2.1, Content Type
Schemas Schema) to fully define the behaviors of the Document Information Panel.

3.5.5 Long Properties

The Long Properties is comprised of a Custom XML Data Storage Part ("[ISO/IEC-29500-1] §15.2.5")
which contains the Long Properties information, and a Custom XML Data Storage Properties Part
("[ISO/IEC-29500-1] §15.2.6") which contains the set of properties for the custom XML data.

 The XML contents of the data storage part conform to the schema defined in Long Properties Schema
(§3.5.5.1, Long Properties Schema).

The root element of the Custom XML Data Storage Part shall be LongProperties (§3.5.5.1.1.2,
LongProperties).

The Associated XML Schema ("[ISO/IEC-29500-1] §22.5.2.2; schemaRef") for this Custom XML Data
Storage Part shall be “http://schemas.microsoft.com/office/2006/metadata/longProperties”.


3.5.5.1 Long Properties Schema

Long properties define a set of properties used to store server property values exceeding 255
characters in length.

3.5.5.1.1 Elements

3.5.5.1.1.1     LongProp (Custom XML Server Property - Long Property)

This element specifies the full value of a custom server property that exceeds 255 characters. This
property is written out when a document is roundtripped to binary and back, to ensure that the full
value of the custom property is not lost. When the first 255 characters of the value of the LongProp
agrees with the value of the custom property with the corresponding name, it is assumed that the
custom property was not modified when roundtripped; in that case, the LongProp is considered to
contain the correct, full property value. If instead the first 255 characters of the value of the
LongProp and the custom property of the same name differ, the custom property is assumed to have
the more current (and therefore accurate) value for the property.

 Parent Elements

 LongProperties (§3.5.5.1.1.2, LongProperties)

3.5.6 SharePoint Premium High Value Content Solution

SharePoint Premium High Value Content Solution is comprised of a Custom XML Data Storage Part
("[ISO/IEC-29500-1] §15.2.5"), which contains High Value Content Solution information, and a
Custom XML Data Storage Properties Part ("[ISO/IEC-29500-1] §15.2.6"), which contains the set of
properties for the custom XML data.

SharePoint Premium High Value Content Solution allows users to create/edit high value documents
such as contracts, agreements, etc. It consists of various components like templates, snippets, fields
etc. Users can create fields, reusable snippets, and create templates using those fields and snippets.
Once templates are published, they can be used to generate documents at scale.

The XML contents of the data storage conform to the schema defined in SharePoint Premium High
Value Content Solution Schema (§3.5.6.1, SharePoint Premium High Value Content Solution Schema).

The root element of the Custom XML Data Storage shall be Agreements (§3.5.6.1.1.1, Agreements).

The Associated XML schema ("[ISO/IEC-29500-1] §22.5.2.2; schemaRef") for this Custom XML Data
Storage Part shall be “https://schemas.microsoft.com/sharepoint/2024/highvaluecontentsolution”.
