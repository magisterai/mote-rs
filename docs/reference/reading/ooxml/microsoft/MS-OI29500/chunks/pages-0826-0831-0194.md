This simple type specifies that its contents will contain a string. The contents of this string are

       <w:pPr>

       </w:pPr>

consider the following fragment:

       <w:sdtPr>

         ...
       </w:sdtPr>

tag. In each case, the value is of type ST_String, and therefore must be interpreted in the context of
