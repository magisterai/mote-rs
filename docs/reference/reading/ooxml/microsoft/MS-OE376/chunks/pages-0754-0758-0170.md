     Office requires that this shape be a connector.

     Office requires the shape identified by the idcntr attribute to exist.

     Office requires the shape identified by the idsrc attribute to exist.

     Office requires the shape identified by the iddest attribute must exist.

     Office requires these attributes use a reference to an object ID in the form of an object name, as

•    The shape is not stroked.

2.1.1748         Part 4 Section 6.2.3.3, ST_CalloutDrop (Callout Drop Location)

a.   The standard does not specify enumeration values.

Office supports the following enumeration values:

 Enumeration Value               Description

 bottom (Bottom placement)       Specifies that the drop is positioned at the bottom of the shape.

 center (Center placement)       Specifies that the drop is positioned at the vertical center of the shape.

 top (Top placement)             Specifies that the drop is positioned at the top of the shape.

 user (User-defined placement)   Specifies that the drop position is determined by the user.




2.1.1749         Part 4 Section 6.2.3.5, ST_ColorType (Color Type)

a.   The standard indicates the kinds of values that the ST_ColorType simple type uses.

In Office, decimal RGB is specified using rgb followed by three comma-separated values in
parentheses. These values are an ordered set in the range 0-255 and represent the red, green, and
blue components of the color.

[Example:

     < ... color="rgb(95,39,38)" ... >


end example]

b.   The standard states that the value of the ST_ColorType simple type can be specified using three-
     character hexadecimal RGB notation.

     Office does not allow this simple type to be specified in this way.

     type.
