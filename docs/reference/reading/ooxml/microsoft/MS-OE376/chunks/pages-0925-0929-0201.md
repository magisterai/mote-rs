3.1.3.2.3 GLOSSARY

Syntax:

GLOSSARY field-argument

Description: Inserts the glossary entry whose name is specified by text in field-argument.

Regarding XML generation, the field result is the value of the glossary. [Note: This can be arbitrarily
complex and involve VML. end note]

Field Value: The specified glossary entry.

Switches: None.

[Example: Assume the following entries are defined with values of current page number, salutation,
and a notice:

    GLOSSARY "- PAGE -"
    GLOSSARY "Yours truly,"
    GLOSSARY Confidential


When evaluated, they might produce the following results:

     - 13 -
    Yours truly,
    CONFIDENTIAL


end example]
