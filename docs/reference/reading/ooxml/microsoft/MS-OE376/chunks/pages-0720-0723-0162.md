    Office does not support these values on this property.

vvv. The standard places no restrictions on when the allowincell attribute is applicable.

    Excel and PowerPoint do not support this attribute; Word does not support this attribute on inline
    shapes.

www. The standard places no restrictions on when the coordorigin attribute is preserved.

    Office does not preserve this attribute on a shape that references, via the type attribute, a
    shapetype element with the same coordorigin value.

xxx. The standard places no restrictions on when the coordorigin and coordsize attributes are
    preserved on the arc element.

    Office preserves these attributes only when this element has at least one of the following children:
    a path with connection points specified in its connectlocs attribute; a path with a textbox specified
    in its textboxrect attribute; or handles.

yyy. The standard states that values of the dgmnodekind attribute are defined by the XML Schema
    integer datatype.

    Office restricts the values of this attribute to be at least 0 and at most 6, where the values
    represent regular, root, assistant, co-worker, subordinate, auxiliary, and default, respectively.

zzz. The standard places no restrictions on when the coordsize attribute is preserved.

    Office does not preserve this attribute on a shape that references, via the type attribute, a
    shapetype element with the same coordorigin value.

aaaa. The standard places no restrictions on the value of the spt attribute.

    Office requires that the spt attribute on an arc element have a value of 19.

bbbb. The standard places no restrictions on the relationship between the left, margin-left, mso-
   position-horizontal, and mso-left-percent properties on the style attribute.

    Office ignores the left and margin-left properties when either the mso-position-horizontal or mso-
    left-percent property on the style attribute is set, or when an anchor element is present.
