Specifies a language used to determine the currency symbol to display for currency values. For
example, if the culture is en-US, the values in the application will format the values with a dollar sign.
If the culture is fr-FR the application will format the values with a euro sign.

This value conforms to the language tagging conventions of RFC 3066 and later. The pattern
<language>-<REGION> is used, for example, en-US or fr-FR.
