a.   The standard states that this element defines whether the object is always included in

2.1.1788         Part 4 Section 6.4.2.51, RowHidden (Comment's Row is Hidden)

a.   The standard could imply that the RowHidden element may be used to hide a row.

     Office uses RowHidden as an indicator of whether the row of the cell to which this comment points
     is hidden and cannot be used for hiding a row. The hidden attribute of the row element ("[ECMA-
     376] Part 4 §3.3.1.71; row") is used for hiding a row.

a.   The standard defines the meaning of the values true and false for the element.

     Excel reverses the meaning of the values true and false for the SizeWithCells element.


2.1.1790         Part 4 Section 6.4.2.61, TextVAlign (Vertical Text Alignment)

a.   The standard describes a vertical alignment property in terms of horizontal alignment.

     Excel considers the TextVAlign element to specify vertical alignment.


2.1.1791         Part 4 Section 6.4.2.62, UIObj (UI Object Toggle)

a.   The standard doesn't define what a UI Object is.

     Excel considers a UI Object to be a graphical object that the user is not able to interact with.


2.1.1792         Part 4 Section 6.4.2.63, Val (Scroll bar position)

a.   The standard states that the values of this element are defined by the XML Schema integer
     datatype.

     Excel restricts the value of this element to be at least 0 and at most 30000.

b.   The standard indicates that the Val element is used for scroll bars and spinners.

     Excel also uses the Val element for scroll bars on combo boxes and list boxes.


2.1.1793         Part 4 Section 6.4.2.64, ValidIds (Valid ID)

a.   The standard indicates how the ValidIds element is used.

     Excel ignores the ValidIds element and does not preserve it on file save.


2.1.1794         Part 4 Section 6.4.2.68, WidthMin (Minimum Width)

a.   The standard indicates the WidthMin element is used for list boxes and dropdowns.

     Excel uses the element WidthMin for dropdowns only.

2.1.1795     Part 4 Section 6.4.3.3, ST_TrueFalseBlank (Boolean Value with Blank
      State)

a.   The standard states that the value f on the ST_TrueFalseBlank simple type is equivalent to logical
     false.

     Excel treats the value f on this simple type as logical true.

     This note applies to the following products: 2007, 2007 SP1, 2007 SP2.


2.1.1796         Part 4 Section 6.5.2.2, textdata (VML Diagram Text)

     For additional notes that apply to this portion of the standard, please see the notes for group,
     §6.1.2.7(a).

a.   The standard does not define the format of the part referenced by the id attribute.

     Office formats the part referenced by the id attribute according to the PowerPoint 97-2003 Binary
     File Format (.ppt) Structure Specification [MS-PPT].

     This note applies to the following products: 2007, 2007 SP1, 2007 SP2.


2.1.1797         Part 4 Section 7.1, Math

a.   The standard states that the oMathPara element is the outermost equations element.

     Word writes inline equations as oMath elements that are not contained in any oMathPara element.

     This note applies to the following products: 2007, 2007 SP1, 2007 SP2.

b.   The standard specifies that the ruby element is allowed inside math.

     Word exhibits unpredictable behavior if the ruby element is included inside math, including failing
     to open the document.

c.   The standard specifies that comments are allowed inside math.

     In Office, unpredictable behavior occurs when comments are included inside math.

d.   The standard specifies that the pict element is allowed inside math.

     Word exhibits unpredictable behavior when the pict element is included inside math, including
     failing to open the document.


2.1.1798         Part 4 Section 7.1.2.1, acc (Accent)

     For additional notes that apply to this portion of the standard, please see the notes for oMath,
     §7.1.2.77(d).


2.1.1799         Part 4 Section 7.1.2.3, aln (Alignment)

a.   The standard states that aln is not used when applied to a box which is not an operator emulator.

     Office does not allow aln to be applied to a box which is not an operator emulator.

b.   The standard says aln applies only to the box function even though the schema allows it as a child
     of math runs.

     In Word, the aln element applies to the box function and to math runs.
