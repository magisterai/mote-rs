     For additional notes that apply to this portion of the standard, please see the notes for oMath,

     Word limits the occurrences of this element to 256.


2.1.1840         Part 4 Section 7.1.2.61, mathFont (Math Font)

a.   The standard does not limit the length of the value of the val attribute.

     Word restricts the value of this attribute to be at most 31 characters.

b.   The standard says that the mathFont property is the default math font.

     Word uses this setting when math is created while editing within the application, but not when
     loading math from a file.

c.   The standard does not specify conditions under which the default math font should be ignored.

     Word ignores the default math font if it is set to an empty string or font which is not appropriate
     for displaying math.

d.   The standard implies that the val attribute is optional.

     Word requires this attribute.


2.1.1841         Part 4 Section 7.1.2.63, maxDist (Maximum Distribution)

a.   The standard says maxDist causes the equation array to be spaced to the maximum width of the
     containing element (page, column, cell, and so on).

     In Word, maxDist causes the equation array to be spaced to the column width.

     This note applies to the following products: 2007, 2007 SP1, 2007 SP2.

b.   The standard allows maxDist to be used in an equation array without alignment points, but does
     not specify where that space should be added.

     In Word, maxDist only affects eqArr contents if alignment points are used to specify where space
     should be added.


2.1.1842         Part 4 Section 7.1.2.64, mc (Matrix Column)

a.   The standard says the mc element specifies the properties of a single column in a matrix.

     Word uses mc to specify the properties of a set of adjacent columns in a matrix.


2.1.1843         Part 4 Section 7.1.2.67, mcs (Matrix Columns)

a.   The standard allows an unbounded number of columns in a matrix.

     Word allows at most 64 columns in a matrix.

a.   The standard states that the pos element specifies the position of the bar in the bar object.
