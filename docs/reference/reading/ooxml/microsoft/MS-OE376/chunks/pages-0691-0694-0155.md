a.   The standard specifies on and off as valid values for the val attribute.

     Office does not consider on and off to be valid values for this attribute.

     This note applies to the following products: 2007, 2007 SP1, 2007 SP2.

     Office always applies protection to the user interface when this element is present, regardless of
     the value the val attribute.

c.   The standard states that this element specifies that the protection applies to the user interface
     only, and not to changes made through the object model.

     Office does not provide a way to set this property or save a file with this element. On load this
     element is treated as specifying standard protection.

d.   The standard states that the default value of the val attribute is true.

     Office uses a default value of false for this attribute.

     This note applies to the following products: 2007, 2007 SP1, 2007 SP2.

2.1.1616         Part 4 Section 5.7.2.228, varyColors (Vary Colors by Point)

     For additional notes that apply to this portion of the standard, please see the notes for stockChart,
     §5.7.2.199(a).

a.   The standard states that the default value of the val attribute is true.

     Office uses a default value of false for this attribute.

     This note applies to the following products: 2007, 2007 SP1, 2007 SP2.

b.   The standard specifies on and off as valid values for the val attribute.

     Office does not consider on and off to be valid values for this attribute.

     This note applies to the following products: 2007, 2007 SP1, 2007 SP2.

c.   The standard states that each point shall have a different color.

     In Office, this element also specifies that marker types shall vary by point.

d.   The standard states that each data marker in the series shall have a different color.

     In Office, this element specifies that each data point, marker, and slice in the series shall vary by
     color.

e.   The standard states that parent elements include area3DChart, areaChart, stockChart, and
     radarChart.

     Office ignores this element and does not vary colors by point when the parent is area3DChart,
     areaChart, or stockChart or when the parent is radarChart with the val attribute of sibling element
     radarStyle set to filled.

f.   The standard does not state any exceptions as to when the vary colors by point is applied.

     Office ignores this element and does not vary colors by point when multiple series are specified on
     the chart.


2.1.1617         Part 4 Section 5.7.2.229, view3D (View In 3D)

a.   The standard states view3D is a child of any chart element.

     In Office, view3D applies when the descendants of the parent chart include area3DChart,
     bar3DChart, line3DChart, pie3DChart, surface3DChart, or surfaceChart.

a.   The standard states the val attribute specifies the layout mode for the width.

     In Office, the val attribute specifies the layout mode for the parent element.

b.   The standard states that edge is a valid value of the val attribute for wMode.

     Office only saves a val of factor. Files opened with val equal to edge will be changed to factor on
     save and the val of sibling element w will be updated to reflect this mode change and correctly
     preserve the manual size.
