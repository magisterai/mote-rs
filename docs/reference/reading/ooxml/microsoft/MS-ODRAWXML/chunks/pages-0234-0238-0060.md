2.24.3.71        CT_Offset

Target namespace: http://schemas.microsoft.com/office/drawing/2014/chartex

Referenced by: CT_ChartTitle, CT_AxisTitle, CT_Legend

An offset from an automatic position.

If this element has a parent CT_FeatureExtension (section 2.24.3.31) element, its “feature” attribute
MUST equal “mp”. Otherwise this element’s parent CT_ChartSpace (section 2.24.3.15) element MUST
contain either a version attribute greater than or equal to “1.0” or a featureList attribute containing
“mp”.

Attributes:

top: A double ([XMLSCHEMA2/2] section 3.2.5) attribute that specifies a vertical offset in inches, with
positive values to the bottom.

left: A double ([XMLSCHEMA2/2] section 3.2.5) attribute that specifies a horizontal offset in inches,
with positive values to the right.

The following W3C XML Schema ([XMLSCHEMA1/2] section 2.1) fragment specifies the contents of this
complex type.

    <xsd:complexType name="CT_Offset">
      <xsd:attribute name="top" type="xsd:double" use="required"/>
      <xsd:attribute name="left" type="xsd:double" use="required"/>
    </xsd:complexType>


See section 5.22 for the full W3C XML Schema ([XMLSCHEMA1/2] section 2.1).

2.24.3.73        CT_PageSetup

Target namespace: http://schemas.microsoft.com/office/drawing/2014/chartex

Referenced by: CT_PrintSettings

A complex type<469> that specifies page setup settings.

Attributes:

paperSize: An unsignedInt ([XMLSCHEMA2/2] section 3.3.22) attribute<470> that specifies the
paper size as defined by Windows.

firstPageNumber: An unsignedInt ([XMLSCHEMA2/2] section 3.3.22) attribute<471> that specifies
the page number for the first printed page.

orientation: An ST_PageOrientation attribute<472> that specifies the page orientation.

blackAndWhite: A Boolean ([XMLSCHEMA2/2] section 3.2.2) attribute<473> that specifies whether
to print in black and white (true) or in color (false).

draft: A Boolean ([XMLSCHEMA2/2] section 3.2.2) attribute<474> that specifies whether to print
without including graphics (true), or print with graphics (false).

useFirstPageNumber: A Boolean ([XMLSCHEMA2/2] section 3.2.2) attribute<475> that specifies
whether to use firstPageNumber and do not auto number (true), or start auto-numbering on the
first page (false).

horizontalDpi: An int ([XMLSCHEMA2/2] section 3.3.17) attribute<476> that specifies the horizontal
print resolution of the device in dots per inch.

verticalDpi: An int ([XMLSCHEMA2/2] section 3.3.17) attribute<477> that specifies the vertical print
resolution of the device in dots per inch.

copies: An unsignedInt ([XMLSCHEMA2/2] section 3.3.22) attribute<478> that specifies the
number of copies.
