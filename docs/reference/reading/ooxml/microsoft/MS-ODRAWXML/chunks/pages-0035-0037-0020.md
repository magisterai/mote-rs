2.2   Extensions

This section specifies the elements from the Office Open XML file formats as specified in
[ISO/IEC29500-1:2016] that are extended by this format. Either the Ignorable attribute
([ISO/IEC29500-3:2015] section 7.2), the AlternateContent elements ([ISO/IEC29500-3:2015]
section 7.5), or the extLst element ([ISO/IEC29500-1:2016] section 20.1.2.2.15, [ISO/IEC29500-
1:2016] section 21.2.2.64, or [ISO/IEC29500-1:2016] section 21.4.2.13) MUST be used to maintain
compatibility with Office Open XML file formats as specified in [ISO/IEC29500-1:2016].
