2.24.3.31        CT_FeatureExtension

Target namespace: http://schemas.microsoft.com/office/drawing/2014/chartex

An extensibility container, always inside a CT_Extension with "uri" set to "ext:featex”.

This container can contain any element that would otherwise be valid in the same location as its
parent CT_Extension (section 2.24.3.27) element. Elements and attributes contained in a
CT_FeatureExtension are ignored when calculating the version or featureList attributes on the
CT_ChartSpace (section 2.24.3.15) element.

Attributes:

feature: A string ([XMLSCHEMA2/2] section 3.2.1) attribute that specifies the feature contained
inside the CT_FeatureExtension.

drop: An ST_ExtensionDropMode attribute that specifies a best-effort hint to clients that don't
understand this content about when it should not be preserved.

The following W3C XML Schema ([XMLSCHEMA1/2] section 2.1) fragment specifies the contents of this
complex type.

    <xsd:complexType name="CT_FeatureExtension">
      <xsd:sequence>
        <xsd:any processContents="lax"/>
      </xsd:sequence>
      <xsd:attribute name="feature" type="xsd:string" use="required"/>
      <xsd:attribute name="drop" type="ST_ExtensionDropMode" use="optional" default="never"/>
    </xsd:complexType>


See section 5.22 for the full W3C XML Schema ([XMLSCHEMA1/2] section 2.1).
