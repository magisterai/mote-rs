A complex type<274> that specifies a chart title.

Child Elements:

tx: A CT_Text element<275> that specifies the custom text.

spPr: A CT_ShapeProperties ([ISO/IEC29500-4:2016] section A.4.1) element<276> that specifies
the OfficeArt shape properties for the chart title.

txPr: A CT_TextBody ([ISO/IEC29500-1:2016] section A.4.1) element<277> that specifies the
OfficeArt text properties for the chart title as a single paragraph with no text runs. Any further
paragraphs, and any text runs in the first paragraph, are ignored.

offset: A CT_Offset element that specifies a custom position for this element.

extLst: A CT_ExtensionList element<278> that specifies an extensibility container.

Attributes:

pos: An ST_SidePos attribute<279> that specifies the side position of the chart title.

align: An ST_PosAlign attribute<280> that specifies the alignment along the side position of the chart
title.

overlay: A boolean ([XMLSCHEMA2/2] section 3.2.2) attribute<281> that specifies whether the
chart title is floating on the chart area and excluded from normal layout (true), or not (false).

The following W3C XML Schema ([XMLSCHEMA1/2] section 2.1) fragment specifies the contents of this
complex type.

    <xsd:complexType name="CT_ChartTitle">
      <xsd:sequence>
        <xsd:element name="tx" type="CT_Text" minOccurs="0" maxOccurs="1"/>
        <xsd:element name="spPr" type="a:CT_ShapeProperties" minOccurs="0" maxOccurs="1"/>
        <xsd:element name="txPr" type="a:CT_TextBody" minOccurs="0" maxOccurs="1"/>
        <xsd:element name="offset" type="CT_Offset" minOccurs="0" maxOccurs="1"/>
        <xsd:element name="extLst" type="CT_ExtensionList" minOccurs="0" maxOccurs="1"/>
      </xsd:sequence>
      <xsd:attribute name="pos" type="ST_SidePos" use="optional" default="t"/>
      <xsd:attribute name="align" type="ST_PosAlign" use="optional" default="ctr"/>
      <xsd:attribute name="overlay" type="xsd:boolean" use="optional" default="0"/>
    </xsd:complexType>


See section 5.22 for the full W3C XML Schema ([XMLSCHEMA1/2] section 2.1).
