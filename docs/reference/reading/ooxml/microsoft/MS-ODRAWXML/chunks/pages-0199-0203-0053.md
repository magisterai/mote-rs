2.24.3.9         CT_Binding

Target namespace: http://schemas.microsoft.com/office/drawing/2014/chartex

Referenced by: CT_Bindings

A named reference to a specific piece of chart data.

If this element has a parent CT_FeatureExtension (section 2.24.3.31) element, its “feature” attribute
MUST equal “dash”. Otherwise this element’s parent CT_ChartSpace (section 2.24.3.15) element
MUST contain either a version attribute greater than or equal to “1.1” or a featureList attribute
containing “dash”.

Attributes:

name: A string ([XMLSCHEMA2/2] section 3.2.1) attribute that specifies the name of the binding.

id: An ST_DataId attribute that specifies the ID of the chart data associated with this binding. Each
ST_DataId can only be referenced by a single binding.

type: An ST_BindingType attribute that specifies the data dimension type associated with this binding.

The following W3C XML Schema ([XMLSCHEMA1/2] section 2.1) fragment specifies the contents of this
complex type.

    <xsd:complexType name="CT_Binding">
      <xsd:attribute name="name" type="xsd:string" use="required"/>
      <xsd:attribute name="id" type="ST_DataId" use="required"/>
      <xsd:attribute name="type" type="ST_BindingType" use="required"/>
    </xsd:complexType>


See section 5.22 for the full W3C XML Schema ([XMLSCHEMA1/2] section 2.1).

2.24.3.14         CT_ChartData

Target namespace: http://schemas.microsoft.com/office/drawing/2014/chartex

Referenced by: CT_ChartSpace

A complex type<264> that specifies the data source for the chart object.

Child Elements:

externalData: A CT_ExternalData element that specifies the external data used for the chart.

This element specifies the relationship to the data for this chart. The data can be linked, pointing to a
spreadsheet in another file. Alternately, the data can be embedded, contained in a separate part
within the same XML package containing the chart. Embedded data is stored as an embedded
Spreadsheet object in Office Open XML format.

This element is not used by a spreadsheet application, as the spreadsheet application can maintain its
own reference to the data in the spreadsheet by using the CT_Formula element.

data: A CT_Data element<265> that specifies the data used for the chart.

extLst: A CT_ExtensionList element<266> that specifies an extensibility container.

The following W3C XML Schema ([XMLSCHEMA1/2] section 2.1) fragment specifies the contents of this
complex type.

    <xsd:complexType name="CT_ChartData">
      <xsd:sequence>
        <xsd:element name="externalData" type="CT_ExternalData" minOccurs="0" maxOccurs="1"/>
        <xsd:element name="data" type="CT_Data" minOccurs="1" maxOccurs="unbounded"/>
        <xsd:element name="extLst" type="CT_ExtensionList" minOccurs="0" maxOccurs="1"/>
      </xsd:sequence>
    </xsd:complexType>


See section 5.22 for the full W3C XML Schema ([XMLSCHEMA1/2] section 2.1).

spPr: A CT_ShapeProperties ([ISO/IEC29500-1:2016] section A.4.1) element<269> that specifies

featureList: A string ([XMLSCHEMA2/2] section 3.2.1) attribute that specifies a space-delimited list of
additional features used in this chart but not already included in its version number.

form of a relationship ID (([ISO/IEC29500-1:2016] section 22.8.2.1) to an image. This image
