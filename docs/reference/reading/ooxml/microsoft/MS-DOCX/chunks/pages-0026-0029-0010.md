The collapsed global element<19> is a CT_OnOff (as specified in [ISO/IEC29500-1:2016] section
A.1) element that, when added to a paragraph (pPr element as specified in [ISO/IEC29500-1:2016]
section 17.7.5.2), specifies the appearance of subsequent paragraphs.

When a collapsed element is added to a paragraph (pPr element as specified in [ISO/IEC29500-
1:2016] section 17.7.5.2) of a particular heading level and its value is "true", "on", or "1",
immediately subsequent paragraphs with a higher heading level number appear collapsed when the
document is opened.

The following W3C XML Schema ([XMLSCHEMA1/2] section 2.1) fragment specifies the contents of this
element.

    <xsd:element name="collapsed" type="w12:CT_OnOff"/>


See section 5.2 for the full W3C XML Schema ([XMLSCHEMA1/2] section 2.1).
