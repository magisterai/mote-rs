sortOrder: An ST_TabularSlicerCacheSortOrder attribute that specifies how the table slicer items are

customListSort: A Boolean ([XMLSCHEMA2/2] section 3.2.2) attribute that specifies whether
custom lists are used when sorting the table slicer items.

 Value     Meaning

 "true"    Custom lists are used when sorting the table slicer items.
