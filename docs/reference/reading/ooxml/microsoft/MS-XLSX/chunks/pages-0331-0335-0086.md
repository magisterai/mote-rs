2.6.258          CT_PivotCacheRichInfo

Target namespace: http://schemas.microsoft.com/office/spreadsheetml/2022/pivotRichData

Referenced by: richInfo

This complex type specifies extended information about a PivotTable cache that contains Rich Data
(section 2.3.6).

Attributes:

pivotCacheGuid: An ST_Guid ([ISO/IEC29500-4:2016] section 22.9.2.4) attribute that specifies the
id for this PivotCache. MUST be equal to the pivotCacheId attribute of the preceding
CT_PivotCacheDefinition (section 2.6.33).

pivotIgnoreInvalidCache: A boolean ([XMLSCHEMA2/2] section 3.2.2) attribute that specifies that
the ignore attribute on the associated CT_PivotCacheDefinition ([ISO/IEC29500-1:2016] section
18.10.1.67) record SHOULD be ignored if the richPivotRecords part is used.

r:id: An ST_RelationshipId ([ISO/IEC29500-1:2016] section 22.8.2.1) attribute that specifies the
unique identifier that corresponds to the related richPivotRecords part. See pivotCacheRecords
([ISO/IEC29500-1:2016] section 18.10.1.67) for more information.

The following W3C XML Schema ([XMLSCHEMA1/2] section 2.1) fragment specifies the contents of this
complex type.

    <xsd:complexType name="CT_PivotCacheRichInfo">
      <xsd:attribute name="pivotCacheGuid" use="required" type="x:ST_Guid"/>
      <xsd:attribute name="pivotIgnoreInvalidCache" use="optional" type="xsd:boolean"
    default="false"/>
      <xsd:attribute ref="r:id" use="optional"/>
    </xsd:complexType>


See section 5.33 for the full W3C XML Schema ([XMLSCHEMA1/2] section 2.1).


2.6.259          CT_Version

Target namespace:
http://schemas.microsoft.com/office/spreadsheetml/2024/workbookCompatibilityVersion

Referenced by: CT_WorkbookCompatibilityVersionExt, version

A complex type that specifies information about the Compatibility Version

Attributes:

warnBelowVersion: An unsignedInt ([XMLSCHEMA2/2] section 3.3.22) attribute that specifies the
minimum Compatibility Version to support workbook contents at the current Compatibility Version for
the workbook. The value MUST NOT be 0.

setVersion: An unsignedInt ([XMLSCHEMA2/2] section 3.3.22) attribute that specifies the
Compatibility Version for the workbook. This value MUST NOT be less than warnBelowVersion value.
