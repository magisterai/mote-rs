specifies the extended properties of an external connection, as specified in [ISO/IEC29500-1:2016]
section 18.13. If this element exists, the type attribute of the ancestor CT_Connection element, as
specified in [ISO/IEC29500-4:2016] section A.2, MUST be equal to "5". See section 2.2.4.1 for how
this element integrates with the Office Open XML file formats specified in [ISO/IEC29500-1:2016].

element.
