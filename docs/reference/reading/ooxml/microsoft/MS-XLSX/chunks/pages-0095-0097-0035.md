2.3.6.1.7.1        Linked Entity and Linked Entity Core Types
All Linked Entities MUST contain a Linked Entity Core Value, which represents the information received
from the service.

The Linked Entity rich value type is identified by having a CT_RichValueStructure (section
2.6.180) t attribute of "_linkedentity" and MUST have the following key value pair (KVP):
