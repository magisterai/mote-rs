2.3.6.1.10       Stock History Cache Type

The rich value type for a stock history cache represents an optional cache of the historical stock data
from the service. This rich value might not be persisted when saved. This cache exists for
performance reasons only.

This rich value type is identified by having a a CT_RichValueStructure (section 2.6.180) t attribute
of "_stockhistorycache".
