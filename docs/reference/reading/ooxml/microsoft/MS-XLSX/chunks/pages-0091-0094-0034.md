The rich value type is indicated by a CT_RichValueStructure (section 2.6.180). All type names,
specified by the t attribute, that begin with an underscore symbol MAY have restrictions on required
key value pairs (KVP) and other defined behavior.

The set of key value pairs (KVP) is defined in CT_RichValue (section 2.6.175) and
CT_RichValueStructure (section 2.6.180).

The rich value fallback is optionally defined in CT_RichValueFallback (section 2.6.178) and stands in
place of the rich value for some features.

While there are restrictions on required key value pairs (KVP) for some rich value types (see the sub-
sections of this section for more details), additional key value pairs (KVP) are allowed.
