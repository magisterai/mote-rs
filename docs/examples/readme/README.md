The pure Markdown example alone is rendered in both formats, since its purpose is
to show one unchanged source serving both. The report and the deck are written
separately for their formats. The chart downloads retain editable charts and
embedded workbooks. All sample data is illustrative.

The previews and PDF files are native Mote output. They are not screenshots or
exports of the Office packages. A visual review in Word and PowerPoint remains
outstanding. The [example guide](../../../examples/readme/README.md) records the
fonts, the composition of each source and the regeneration instructions.
