The presentation's Word companion uses document flow for the same visible content.
Other slide downloads use automatic layout. The chart downloads retain editable
charts and embedded workbooks. All sample data is illustrative.

The previews are independently generated native PNGs. They are not screenshots
or exports of the Office packages. Word and PowerPoint visual review remains
pending. The [example guide](../../../examples/readme/README.md) records fonts,
format-specific defaults and regeneration instructions.
